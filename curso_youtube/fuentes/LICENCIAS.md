# Tipografías del curso

Las mismas de las presentaciones del curso «Gestión Financiera 4.0» (Montserrat y Source Sans 3), más una
itálica con serifa para los énfasis y una monoespaciada para rótulos. Todas se distribuyen bajo la SIL Open Font
License 1.1 (https://openfontlicense.org), que permite usarlas, incluirlas y redistribuirlas con el proyecto.
Los archivos vienen de los paquetes de Fontsource.

| Archivo | Familia | Autor |
|---|---|---|
| `montserrat.woff2` | Montserrat | Julieta Ulanovsky y colaboradores |
| `source-sans-3.woff2` | Source Sans 3 | Paul D. Hunt (Adobe) |
| `newsreader-italic.woff2` | Newsreader (itálica) | Production Type |
| `geist-mono.woff2` | Geist Mono | Vercel, Basement Studio |
